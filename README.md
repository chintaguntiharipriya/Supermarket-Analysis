# 🛒 Supermarket Sales Data Analysis

This project focuses on analyzing a supermarket sales dataset to uncover business insights, customer trends, sales behavior, and performance metrics. The analysis includes data cleaning, preprocessing, visualization, feature engineering, and exploratory analysis using Python and analytical libraries.

---

## 📌 Objectives

- Understand customer purchasing patterns  
- Identify high-performing product categories  
- Analyze revenue trends by month, payment method, gender, and branch  
- Build insights for business decision-making  
- Perform feature engineering for deeper insights

## 📈 Key Features & Analysis

- Checked missing values and removed inconsistencies  
- Converted categorical and date/time data types  
- Added new features such as:  
  - `Month`
  - `Hour`
  - `Revenue Category` (High, Medium, Low)
  - `Rating Category` (Excellent, Good, Average)
- Performed grouped analysis on:
  - Branch performance  
  - Gender-based spending  
  - Payment preferences  
  - Best- and worst-performing product categories  

---

## 🔍 Insights & Findings

- Most customers preferred **E-wallets** for payment.  
- **Food and Beverages** product line received the highest ratings.  
- Sales increased during weekends with **31.14% contribution**.  
- The **Alex branch** performed best in terms of revenue.
